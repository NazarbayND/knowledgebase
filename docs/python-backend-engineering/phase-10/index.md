# Phase 10 — Senior engineering interviews

**Week 16 · P0; practice throughout** · Prerequisite: [Phase 9](../phase-9/index.md).

Solve bounded problems and communicate mechanisms, evidence, tradeoffs and uncertainty under time limits.

## Study route

| Module | Read | Practise and assess |
| --- | --- | --- |
| 19 — Coding and technical problem solving | [Core chapters](module-19/index.md) | [Exercises, model answers and assessment](module-19/practice.md) |
| 20 — Senior interview simulation | [Core chapters](module-20/index.md) | [Exercises, model answers and assessment](module-20/practice.md) |

Read for the mechanism, explain one failure, then answer the practice questions
before opening their model answers. Revisit earlier Python/concurrency concepts
when reasoning about ownership, blocking, transactions and shutdown.

## Completion gate

Take the [phase assessment](assessment.md), using the course's 25/30/20/15/10
rubric and 80/100 target. Record evidence in [progress](../progress.md).
