## Evidence record

For each item record date, prompt, independent/hinted outcome, explanation or
artifact link, observed result, remaining limitation and next action. Where a
competency requires implementation, written reasoning is preparatory evidence
rather than a substitute for the unrun behavior.

## Revision priority

Prioritize P0 gaps that block later topics: ownership before async lifetimes,
transactions before outbox, identity before tenant access and resource budgets
before autoscaling. Reattempt a bounded problem without its answer guide, then
update [progress](../progress.md) using actual evidence.
