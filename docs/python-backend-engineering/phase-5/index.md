# Phase 5 — PostgreSQL, SQL and data persistence

**Weeks 7–8 · P0** · Prerequisite: [Phase 4](../phase-4/index.md).

Explain query plans and transaction anomalies, then choose safe inventory concurrency control.

## Study route

| Module | Read | Practise and assess |

before opening their model answers. Revisit earlier Python/concurrency concepts
when reasoning about ownership, blocking, transactions and shutdown.

## Completion gate

Take the [phase assessment](assessment.md), using the course's 25/30/20/15/10
rubric and 80/100 target. Record evidence in [progress](../progress.md).
A lesson being available does not mean the learner has demonstrated its competency.

## Written SQL revision

Before the phase review, work through the
[SQL query workbook](module-9/query-workbook.md). Predict complete rows for joins,
ties, cursor boundaries and window frames before opening the answers.
